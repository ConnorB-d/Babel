# Babel — Game Ideas

## Ideas for the game

- A daily word-guessing game where players identify a hidden word from its definition.
- The definition is translated through a chain of languages and back into English, creating a distorted clue.
- Everyone receives the same daily puzzle.
- Difficulty could vary based on the translation path and languages used.
- Score players based on how many guesses they need.

## Ideas for game details

### Current rules

- Start with a clue that has gone through 10 translations.
- After each wrong guess, reduce the translation depth by one.
- As the translation depth decreases, the definition should become more accurate and easier to understand.

### Details to decide

- How many guesses does a player get?
- Does the player win by guessing the word, or is there another success condition?
- What should happen when the player runs out of guesses?
- Which languages and translation paths should be used?
- How should the translation depth relate to the number of guesses and score?
- How will each daily word and translated clue be selected and checked?
